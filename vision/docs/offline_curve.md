## 运行

从项目根目录PowerShell使用现有环境，无需新增依赖：

```powershell
vision/.venv/Scripts/python.exe vision/tools/replay_curve_offline.py --input vision/data/captures/final_mount_20261108/v03_center_0007 vision/data/captures/final_mount_20261108/v03_center_0008 --output vision/build/curve_c1_entry
vision/.venv/Scripts/python.exe vision/tools/check_curve_offline.py --output vision/build/curve_c1_recheck
```

两个入口均拒绝覆盖已有输出目录；复跑须指定新的目录。第一条用于所选原图会话，第二条复跑旧325张、V-03五姿态15张及V-06六组18张。校验器依赖本机原始采集、既有V-03／V-06证据及`vision/build/offline_v02_r1/frames.jsonl`和`parameters.json`；这些被忽略的旧build文件不能假定随Git同步。已有358张检查在[validation.json](../../testing/2026-11-08_vision_curve_c1/validation.json)，无需覆盖重跑。

输出包括参数、逐帧JSONL、摘要CSV、叠加、MP4及实际解码帧数。完整检查另存保护文件哈希、源码快照、三张六场景拼图和失效序列。输入只匹配`data_数字.jpg`，不读取dbg或损坏的旧采集CSV。MP4的10fps是人工播放速度，电脑算法计时不包含读图／绘制／保存／视频编码，不表示K230实时性能。

## 输出含义

[offline_curve.py](../src/offline_curve.py)调用冻结R1的`detect()`，其全部原字段保持原义、逐项比较358张一致。新增内容放在`curve_observation`：

| 字段 | 含义 |
| --- | --- |
| 原有`valid`、`reference_y`、`deviation_px` | 固定y120双边偏差是否可用；近弯仍为false／120／null |
| `near_field.available`、`y_range`、`centerline` | 新增观测通过支持数、跨度、质量、宽度增长、近场覆盖及双黑带关联检查后，保留同帧真实双边中点；不外推，不另给可混用的偏差 |
| `accepted_pair_samples` | 新候选实际接受的双边段；为空表示没有接受，不删除R1原始候选诊断 |
| `corners` | 与已观测左右内缘分别关联的轮廓肘部、入弯／出弯臂端点和支持误差，均为图像像素 |
| `turn_hint` | 仅在两侧肘部同向且无方向歧义时给left／right；其余null，不表示地面转角或转向指令 |
| `status` | `paired_bend_observed`、`near_field_only`或`insufficient_observed_geometry` |
| `full_turn_path_available`、`control_ready` | 当前始终false，明确候选尚未提供整弯可行轨迹或上车结果 |

新增关联检查比R1严格。部分原本R1有效的直道／偏航图没有通过新增连通域检查，其固定偏差仍保持有效；不能把`near_field.available=false`解释成原识别退化或替代R1的`valid`。本轮旧325张新增近场／转角均未通过，原162张有效固定偏差原样保留；最终安装五姿态的15张固定偏差也全部保留。

## 观测方法与边界

近弯唯一失败项为固定参考行未覆盖时，允许另存y更大的实测双边段，且原有支持数／跨度／质量／透视增长检查须全部通过、最靠近端至少到y200。固定参考行结果保持空，不移动y120来制造有效。中点只取相同y的两个真实端点之平均，不根据50cm宽度补另一边。

二维连通域仅用R1同一全局灰度阈值，在y30～215找连续黑带，不做闭运算补连接。R1三行中值边缘与原单行可能差1像素，查询连通域仅朝已观测黑段内部偏移1像素，原内缘坐标不移动。至少85%的该侧样本关联同一长黑带，左右必须是不同连通域。新增形状区上移至y30，目的是观察入口外侧约y50的肘部；不改变R1原ROI和参考行。

轮廓以6像素容差简化，仅找具有较长向下入弯臂、近水平出弯臂的图内顶点；至少6个该侧实测点须贴合有限入弯线段，误差≤6像素。排除图像／ROI裁切端点，避免图框假转角；至少两侧同向才提示右／左展开。容差和形状假设是在现有图上开发的启发式参数，不能作为官方要求、盲测结果或所有视角下的锐角检测器。可能拒绝强偏航、其他透视姿态和短出弯臂。

同一斜带的两面不是道路双边。拟弯中及文字组R1内部原有2／3行错误候选仍以原字段保留，C1在新增已接受双边、近场中点与转角中排除这些短错配；不能称为完全消除了印字候选。全无图／单带／文字／无对比等失效后新增方向、路径每帧清空，绝不沿用入口的右转提示。

拼图紫色仍为R1固定中线、青色中心点为C1近场中点、黄色圆圈为关联肘部。原R1青色条带／淡蓝单边散点仍是角色未定候选，图中保留这些诊断不意味着C1接受了路径。原图未修改。

当前连续黑带的连通关系不能直接用于官方分离5cm色块。尚无官方色块间隙、动态连续转向、完整地面标定、车体包络、控制路径生成、板上实时性能和自动一圈证据。比赛图示77°是场景标签，不能从这些透视轮廓得出电机应右转77°。本轮依据比赛第三部分、图1及表1，支持基本功能60分的提前识弯／避免碰边出界和报告20分论证，不给出实测加分结论。
