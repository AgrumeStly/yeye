## 现在主控只做一次居中采集

1. 断开电机动力，相机固定在车上，车在直道居中摆正。TF卡留在开发板，沿用已确认的视觉板连接方式；本说明不改变电源接法。
2. VS Code打开`vision/vision.code-workspace`，再打开[src/capture_canmv.py](../src/capture_canmv.py)。当前默认`POSE="center"`、`FRAME_COUNT=3`、`PREVIEW_ONLY=True`先核验预览；画面确认后，停止脚本并改为`PREVIEW_ONLY=False`再执行以下3张保存流程。
3. 命令面板依次运行 **CanMV: 连接开发板**、**CanMV: 启用预览**、**CanMV: 运行当前 Python 脚本**。使用CanMV扩展，不能点电脑Python的运行按钮；不保存为main.py／boot.py、不刷固件。命令名称已核对本机扩展0.9.10中文资源。
4. 程序初始化后显示灰度预览，丢弃30帧，然后倒计时约5秒，保存3张并自动结束。预期终端依次出现`[SESSION]`、`[READY]`、`[COUNTDOWN]`、3条`[SAVED]`和`[DONE]`。若报错，保留完整终端内容和当前生成的会话；不能把报错后残留图片当作成功。
5. 图片在板上TF卡`/sdcard/captures/v03_center_0001/`，重跑自动选`0002`等新目录。以终端打印的`[SESSION]`路径为准。包括`data_0001.jpg`至`data_0003.jpg`、`session.json`和`frames.jsonl`。通过CanMV扩展开发板文件面板下载整个会话，或程序结束后断电取卡复制，保存到电脑`vision/data/captures/`下新的同名目录；不要直接覆盖旧批次。

若本机CanMV命令连接失败，停在连接这一步保留错误；不要换驱动／刷固件来猜。程序默认CSI2、挂载点`/sdcard`，来自厂家示例；实际插座或挂载点不同须按真实情况修改配置，不自动探测并切换。板上没有`media.sensor`等模块时，说明当前固件API不匹配，需核对固件版本后再适配。

## 配置与证据边界

- 默认输出只有320×240灰度JPEG，预览不画线，原图不二值化。JPEG为有损压缩，因此保留的是未叠加的采集输入，不称为无损传感器RAW。
- 姿态标签可选`center`、`offset_left`、`offset_right`、`heading_left`、`heading_right`，只是主控在配置区填的标签，不是算法测量；先检查居中3张，通过后再逐项指导其他姿态。
- 高度／俯角未实测保持`None`；默认不填写距离参照线。仅本次真摆了距车头最前沿20／40／60cm的线，才填`REFERENCE_FRONT_CM=[20,40,60]`；不自动沿用旧`ref_0001`的场景事实。
- 自动曝光沿用固件默认，不调用未经本机固件核对的锁曝光、增益或自动对焦API。元数据明确记`firmware_auto_not_locked`，不编造曝光值。
- 未调用显式裁剪／ROI，记录固件默认策略；不能保证与旧1280×960彩色参照图视场相同，不能直接把旧坐标除以4当距离标定。
- 记录每次snapshot调用前后ticks、回绕安全的相对时间、编码文件大小与SHA-256。时间不是曝光时刻、完整延迟或硬件同步时间；500ms是最小间隔，不代表固定真实帧率。
- 写卡／校验／采图中断时会话标记failed或interrupted，保留部分产物；TF卡故障不能靠本程序保证修复。关闭文件、同步、元数据改名和异常释放均有处理，突发断电仍可能损坏元数据，电脑检查会拒绝不一致结果。

### 2026-11-08板上EEXIST修复

首次保存模式在预热后更新session.json时失败，板上错误为`[Errno 17] EEXIST`。当前固件的`os.rename`不覆盖已存在目标，初版电脑模型通过os.replace没有覆盖此差异。v2统一使用rename，仅在EEXIST且目标不是目录时移除本次会话的旧session.json，再将已写完并同步的.tmp改名；其他错误上报并保留原目标。两步之间不保证断电原子性，若失败保留.tmp、整组不作完整会话验收。

新增模型首先在旧版复现同一位置EEXIST，再验证修复后的重复更新／新会话不覆盖、权限错误不删除原文件、第二次改名失败保留临时文件及旁侧证据。电脑12项通过，板上待重跑。保留失败会话，不删目录、不格式化卡；重跑自动使用新编号。主控保存／重载本地v2脚本，移走尺子并保持居中静止，再用CanMV运行，确认终端版本`capture-canmv-2`及3条[SAVED]／[DONE]。
