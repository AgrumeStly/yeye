### 01 / 目标与执行口径

硬件已购买完成。接下来依次完成到货验收、组装、基础驱动、视觉循迹、整车联调、语音与停车、稳定性验证及答辩。采购完成不等于模块已验证；首周核对实物型号、接口和音频链路。

时间投入：按三人各每周约3个整天、尽量同步安排估算。每人每周计划任务2.5天，预留0.5天修复；第8周约2天用于赛前准备，另预留12月5日参赛。具体到场日期由三人在10月12日确定。

正式节点：报名截止10月25日23:59；验收暂定12月5日，以赛事群后续通知为准。本文全部日期均为2026年北京时间；内部任务默认截止当日21:00。

### 02 / 成功标准与优先级

第一优先：稳定顺时针完成一圈，单圈不超过5分钟，尽量零触边。第二优先：语音启动、冲线后语音接管3秒内停稳、清晰应答及至少2条自选指令。第三优先：冲线自动停车与稳定基础上的提速。报告从第1周持续留证。

规则硬约束：整车长≤30cm、宽≤20cm、高≤25cm，含电池总重≤5kg，使用可充电电池。语音识别与应答在车上独立完成。正式运行不依赖遥控或场外装置。行驶60分、额外功能40分、报告20分，总分120分。

本文试跑次数、完成率和阶段门槛是队内建议验收标准，不是主办方新增要求。

### 三个工作日如何使用

工作日A：各自完成模块任务，开工前15分钟确认本周目标。工作日B：接口对接与专项测试，前半天开发、后半天联合调试。工作日C：前半天整车回归与验收，后半天留作返工、归档和下周排期。每次收工前留15分钟更新问题清单。

### 关键依赖

供电/接线验收 → 电机及采图正常 → 通信与闭环 → 低速整圈 → 稳定性 → 加分功能与提速 → 冻结。语音可在视觉基础完成后并行，但不能挤占低速完赛的主线。未通过阶段门槛时，下一工作日先消除阻塞。
