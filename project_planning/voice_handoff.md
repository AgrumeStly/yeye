## 已明确的交接边界

- 开发助手：队友电脑上的本地dsh；不是默认的小车运行时组件。仓库不提供或要求复制主控的账号、API密钥和本机认证。
- 硬件：沿用现有K230麦克风和扬声器。采购资料基线为庐山派Lite-K230D／128MB；实际板型、当前CanMV固件、音频API、接线和音量由视觉在接收设备后核对。主控没有要求更换语音模块或重刷现有固件。
- 责任：视觉承接语音，主控协调整车接口并验收，硬件按实际需要协助。主控此前独自承担语音的记录是旧阶段安排，本次按最新交接执行；不自动转交总管身份或全部STM32实现责任。
- 本次仓库整理仅写文档和归档已存在版本；没有新增语音实现、安装队友环境、运行语音测试或操作板卡。

## 比赛语音目标

权威来源：[比赛原文](../competition/比赛文档.md)第三部分项目要求及表1，[PDF](../competition/比赛文档.pdf)优先。

| 官方要求 | 后续开发需要明确并留证的内容 |
| --- | --- |
| 起点语音启动 | 识别真实语音指令，车辆在允许状态下实际出发；开发KEY启动不等于本项完成 |
| 冲线后语音接管，3秒内减速停稳 | 分清语音发生、识别、发送、接收／执行和真实停稳时刻；PWM归零不等于已经停稳 |
| 对上述指令清晰语音应答 | 分清“识别到／已收到请求”与“车辆已执行”的事实，不能虚构动作回执 |
| 不少于2条自选语音指令 | 由视觉与dsh确定词表、语义、应答及演示方式，不能用键盘／遥控代替车端语音识别 |

语音识别和应答须由小车独立完成，不得以人工按键或无线遥控替代。冲线自动停车是另列的额外功能，与语音接管分别验收。额外功能合计40分，官方未给语音分项分值；报告20分中方案及电路／程序设计涉及语音链路。后续只报告真实功能与证据，不预测具体得分。
