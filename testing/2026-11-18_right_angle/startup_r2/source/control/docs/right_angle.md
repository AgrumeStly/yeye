# 左侧首个直角弯程序

2026-11-18，维护：主控。当前为R2／0x02120011，按主控最新要求取消左右轮分别配对，改为一次双轮悬空测试后一次上道。任务[I-04](../../project_planning/tasks/I-04-RIGHT-ANGLE.md)。比赛图1中从起点顺时针到达的左下直角弯是**右转90°**。本版动力过弯仍待验。

## 直接使用

1. 主控在Keil5用 **Project → Open Project** 打开[../MDK-ARM/right_angle.uvprojx](../MDK-ARM/right_angle.uvprojx)，选择唯一目标 **RightAngle**，**Flash → Download**。固件版本`g_speed_revision=0x02120011`；已构建的[R2 HEX](../../testing/2026-11-18_right_angle/release_r2/right_angle.hex)可供核对。接线、SPL、下载器继续沿用当前已跑通配置。
2. K230停止旧直道脚本，运行[right_angle_drive.py](../../testing/2026-11-18_right_angle/release/right_angle_drive.py)。单文件自包含，不需另传模块、不改main.py、不发送START。控制固件只接v4，旧直道v3不能启动此目标。
3. 主控将两只驱动轮悬空，长按实物 **KEY（PA0／WKUP）** 约1～2秒后松开：**第一次两轮同时前进1秒并停**，无需视觉有效。测试完整通过后，保持车载供电，将车放到首弯前约0.5米、顺时针直道中央，待日志ready／有效后，**再长按KEY一次直接跑弯**。不再进行左右单轮测试。两次动作之间等待轮子停稳；运行中KEY立即撤PWM，测试中断不算完成，也不会自动上道。复位会清除本次双轮测试结果，已通过后不用再按RST。

R2直接沿用[当前安装实证映射](../../hardware_preparation/wheel_mapping.md)，不通过同时转两轮重新猜通道。`g_corner_startup.stage=0/1/2`依次表示待双轮测试／正在测试／已通过可上道，`completed=1`才是通过，`ground_runs`记录本次上电后真正进入地面RUN的次数。仅`g_speed_match.phase=2`不再表示已做完本次双轮测试。缺少当前双侧路径时，上道KEY会被拒绝并记`starts_blocked`／`blocked_reason=LAP_PATH`，保持等待，不快闪锁故障。

主控回报的“距离右侧黑线拐角约10cm”可能已进入相机近处盲区，不能保证有启动所需的双边路径；该距离不是本程序已验证的起点，应退至上述弯前直道。旧版首次按键仍可能处于单轮流程，或被上电等待吞掉；快闪只说明故障锁定，未取得该次`reason`前不把它确定为视觉、编码器或电机故障。

默认接近速度60RPM、单次12秒、PWM上限50%。停止状态下可设`g_lap_config.straight_rpm=40..80`、`run_ms=500..15000`、`min_feedforward=0..300`，下次KEY锁定。先使用默认值；这些是队内调试设定，不是官方要求或实测车速。到12秒正常LIMIT后撤PWM滑行；也可在出弯完成后用KEY结束研发试跑，本程序不判定整圈或终点。

## 代码行为

- 视觉只搜索直道和90°右弯，每帧重新验证黑边与白走廊；三帧／80ms稳定后许可。当前双侧近弯允许提前减速，弯道用56代理单位前视点提前转向，出弯直线回到小幅纠偏。现有投影未完成全图标定，不将代理坐标当作实测厘米。
- 近弯只见一侧时，必须已有当前双侧弯道确认、与上一局部模型关联、当前同一边界折角的两臂均有支持，并有可见白色中线；最多2秒等待双侧重获。单侧不能冷启动，强制满弯降速，源年龄上限120ms；空白、历史或不能关联的直黑带撤许可。STM32独立监督2秒租期，连续新单侧包不能延长它。
- 控制每20ms以真实编码器计算左右独立PI，沿用直道02的Kp6／Ki8、转速滤波1/2及目标差速交叉补偿。平均目标随风险由60降至35RPM，差速比例最多100%，右内轮可为0、外轮全弯稳态70RPM、过渡上限90RPM；不倒车。出弯逐步恢复同速，零内轮不触发无反馈，但重新起转后仍受300ms反馈监督。
- 保留KEY急停、UART错误／溢出、200ms双侧源年龄、120ms单侧源年龄、编码器连续性、原始反向／超速、无反馈、IWDG和启动超时。故障锁住，不因画面恢复自动开车。原直道及低速目标BIN已逐字节核对不变。
- R2首次双轮测试固定两轮60RPM、1000ms、50%PWM上限，不采纳视觉差速，PATH无效不影响该悬空测试，但STOP／KEY／电机反馈保护仍生效。结束时要求两轮均有至少20个正向净计数、最后转速均不低于10RPM；这只是队内反馈门槛，不是比赛成绩或重新标定。通过后才开放第二次KEY地面启动。长按从本次按下计时，避免首次正常长按被上电1秒等待吞掉。

## 验证及比赛收益

[本地证据](../../testing/2026-11-18_right_angle/record.md)保存构建、控制模型、真实图方向、单侧分支和协议互通结果。旧手推序列另保留原时间戳；重定时仅检查代码分支，不能当连续现场许可或闭环过弯证明。实板处理耗时、实际转弯半径、车体全投影余量、触边次数和完成率仍待本次直接地面试跑。

对应比赛第三部分项目要求、图1及表1基本功能60分：通过首弯支撑顺时针自主完圈，提前减速与可停内轮用于减少触黑边扣分及完全出界失败。现场记录进出弯时间、是否通过、触边、最大车体偏移、左右目标／实测RPM、PWM及停车原因；同一条件下重复成功后再提高速度以缩短总用时。官方未公布每次触边扣分及时间折算公式，不预测具体加分。KEY研发试跑不能当正式完圈验收。
