# 首个右转直角弯参数基线

2026-11-25，任务 `I-04-RIGHT-ANGLE`。主控现场反馈“现在可以正常拐弯，完全过弯，但是最后停下时还是绿灯快闪”。本次保存车能完整通过首弯的配对发布和默认参数，供后续排查停车时复用。

## 冻结版本

STM32 **RightAngleVoice `0x02120015`** 配对 CanMV **v9**。源码提交 `d28664228eafce99c7807bd9de748d28481d91c4`。视觉脚本与上次 K230 读回一致，STM32 BIN 和 HEX 的哈希与配套构建记录一致。本次归档引用现有发布和主控现场观察，RAM 调参值待核。 [视觉装板回执](../voice_v9_deploy/receipt.json)

恢复时使用同一配对的 [STM32 HEX](right_angle_voice.hex)、[STM32 BIN](right_angle_voice.bin) 和 [K230 主程序](main.py)，校验见 [文件清单](manifest.json)。热点配置沿用视觉板现有文件。 [上道操作](../../../control/docs/right_angle_voice.md)

## 冻结参数

| 项目 | v9 配对发布的默认值 |
| --- | --- |
| 右转几何 | 90°，外入偏置 5、圆弧半径 30、前视 24、名义轮距 14，均为视觉投影代理单位 |
| 入弯 | 当前双边或左纵边与前横边构成的 L。初始路径稳定门为至少 3 帧并跨 80ms |
| 弯中及出弯 | 已确认右弯后，用当前同一前线的法向距离及角度重算弧线，置信度 58。入弯方向相对车头估计达到 −75° 时，用转成纵向的前线作为出弯左边，双边恢复后交回双边循迹 |
| 共同轮速目标上限 | 双边 80 RPM，随弯度降到 60 RPM。L 形 60 RPM，前线或普通单侧 50 RPM，短时白走廊 40 RPM |
| 差速与驱动 | 最大差速比例 65%，单轮目标上限 112 RPM。默认前馈下限 200‰，PWM 上限 500‰ |
| 单次和续行时序 | 运动上限 12 秒，STM32 路径源年龄小于 200ms。已跟踪前线逐帧更新，续接间隔小于 240ms。普通单侧观测期限 1200ms |
| 手机预览 | 端口 8080，JPEG 最小间隔 83ms，与控车共用同一组路径结果 |

关键参数从 [赛车线计算](../../../vision/src/right_angle_racing.py)、[视觉路径选择](../../../vision/src/right_angle_route.py)、[运动策略](../../../control/App/Motion/lap_motion.c)及 [弯道轮速分配](../../../control/Algorithms/Speed/corner_guide.c)核对。轮速为目标值，代理几何未换算成实测厘米。

## 现场观察与待核项

主控已观察到完整过弯。停后连续快闪对应固件的故障灯态，具体停车原因、停止时刻、触边情况和出弯后的距离暂无本轮日志或冻结值。后续如恢复排查，以本参数基线对照 STM32 停车码和同次视觉包序号。
