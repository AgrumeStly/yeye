This skill is enabled by default for all agents working in this project. Assess the current request, existing decisions, and available repository facts at the start of each task.

When a material planning or design decision remains unresolved, read `../grilling/SKILL.md` and follow its interview workflow for that decision. The sibling path is relative to this skill directory; no separate Skill tool is required. Scope the interview to the current task, reuse settled decisions, gather facts from available tools, and ask only for choices that require 主控's judgment. Address team members as 主控、视觉、硬件.

When the request is clear and already authorized, proceed with the work directly. Routine edits, known fixes, and skill installation or configuration requests can be completed without an interview. Default enablement changes invocation, not authorization: preserve the project's explicit-upload requirement and other existing action boundaries.
