# MotorContinuous：实验室第一轮无动力示波器测量单

状态：v1.0，测量说明已准备，仪器及波形未实测。日期：2026-10-24（北京时间）。维护：主控／01；主控现场操作，实验室人员协助探头与接地核对，主控／02归档实际波形。

依据：主控表示“我可以去实验室查看示波器”，尚不等于仪器已借到或测量已通过。[当前持续版的板内启用／KEY停止配对](../testing/2026-10-24_motor_continuous/watch/README.md)已符合，接线已由主控按[自查表](motor_wiring_self_check.md)确认一致。现用MotorContinuous 0x020B1001，只A桥30%／20kHz、KEY人工启停，不再500ms自动停止。**沿用现有程序，不重烧录、不改占空比／频率。**

## 1. 本轮目标与实验室条件

第一轮只看**PE9主控输出端与驱动AIN1输入端**的真实波形。驱动OFF、XT30动力电池始终拔开、UC2及天空星Type-C断开；主板只由既有DAPLink五线供电，不连接电机动力，不测AO1／AO2、Vin或芯片VM。这一轮完成后仍不接动力电池，先带回波形判读。

到实验室先确认数字示波器型号、可用通道、配套探头及保存图片／波形的方法。优先两通道、两支匹配的10×无源探头、配套地线及绝缘小钩／微夹；请实验室人员协助校准信号检查／探头补偿，并确认电脑USB、DAPLink、示波器的接地关系。仪器旋钮／菜单名称以实际型号为准；可先拍仪器正面和探头倍率开关，交01按实际界面说明。

只有一通道时可以先测PE9，再停PWM、断DAPLink后换到AIN1，再次上电及人工触发；两张图只能作顺序测量，不能声称已验证同步相位。没有能稳定接触节点且不碰邻针的夹具时先准备接触条件，不带电挪探头、硬探芯片腿或拿裸钩跨排针。

## 2. 接探头：全部断电时完成

| 项目 | 探头尖端接哪里 | 地夹接哪里 | 识别依据 |
| --- | --- | --- | --- |
| CH1 | 天空星PE9，板背E09，对应P1.15的金属节点 | 已确认的系统公共GND | E09旁是E08，不能夹到E08；[排针资源](../control/docs/pin_plan.md) |
| CH2 | 驱动左下控制口AIN1对应金属节点 | 与CH1相同公共GND，或经确认同网的短回路地 | 驱动开关朝上、元件面朝前时左下第2针；第1针是AIN2 |

保留原PE9→AIN1连接线和两板共地，不拆控制线来腾测点；由实验室人员用合适测试转接／微夹接到可及金属节点。不要让示波器地线代替原共地线。原来电阻检查临时拔下的电机动力线，本轮无需为无动力信号测量插回；如主控已断电复原，保持现状并记录，不带电挪线。

**接地式示波器的普通探头地夹只接系统GND，不夹AO1、AO2、AIN1或其他信号。** 常规接地式示波器通道地与保护地相连；把地夹接桥输出会引入接地短接路径。此前“万用表黑表笔接AO2”仅属于万用表差分电压读数，不能照搬给普通示波器。保留示波器保护地，不用拔保护地、改变电脑供电来假定隔离。依据：[Tektronix接地／浮动测量说明](https://www.tek.com/en/documents/whitepaper/abcs-probes-primer)。本轮没有H桥输出测量；后续若需要，由实验室人员核对合适的差分测量方案后另列步骤。

## 3. 初始设置

以下是针对本工程20kHz／约3.3V逻辑信号的建议初值，不是所有仪器通用菜单或厂家验收阈值。先在仪器校准端验证探头及通道能看到方波，再断开被测板全部供电、按第2节布置测点。

| 设置项 | 建议初值／检查 |
| --- | --- |
| 探头倍率 | 两支探头10×；两个通道显示的探头倍率也为10×，包括自动识别时的显示值 |
| 输入阻抗 | 1MΩ高阻输入；普通10×无源探头不选50Ω终端 |
| 耦合 | 两通道均DC直流耦合；通道启用，零电平标记位于可见区域 |
| 垂直档位 | 先1V/div，零点放下方，能看到约0–3.3V且不削顶 |
| 水平档位 | 先10µs/div，约能显示两个50µs周期；留意µs与ms单位 |
| 采样 | 普通Sample采集，实际采样率建议至少10MS/s，记录实际显示值；暂不做平均以免掩盖启动细节 |
| 触发 | 边沿、CH1、上升沿、约1.5V；先Auto模式，便于无脉冲时也看基线 |
| 自动测量 | 每通道添加Frequency、Period、正脉宽（+Width）、正占空比（+Duty）；幅值同时记录高／低电平 |

倍率与高阻输入的依据见[Teledyne LeCroy关于10×无源探头的说明](https://blog.teledynelecroy.com/2018/10/secrets-of-10x-passive-probe.html?showComment=1619635591555)；实际探头匹配与补偿按实验室仪器手册执行。手动游标可用于复核周期与高时间，不只依赖仪器自动测量的单个数字。

## 4. 一次人工采集

1. 动力电池始终拔开。全部被测板断电时接好探头，检查地夹和尖端位置，再接DAPLink USB给天空星供电。驱动仍OFF，主板Type-C空着。轮子悬空，保持现有电机／驱动接线状态。
2. Keil可以退出调试；本轮不依赖Watch、不点Download。若主控保留调试会话，则维持F5 Run、禁用断点，不暂停CPU。复位后KEY松开，等每组1闪待机；此前已停止锁定的状态可通过本次断电重启回到待机。
3. 示波器进入Run、显示CH1／CH2。待机两点应接近低电平；若没有基线，先检查DC耦合、通道开关、倍率及夹具，不把触发等待当“MCU没PWM”。
4. KEY长按约1–2s到绿灯常亮，**松开**后再观察；按住常亮只是ARMED提示，不是已经运行。松开稳定后才应出现脉冲。
5. 波形稳定后，由实验室人员或主控按**示波器的Run/Stop**冻结画面，再按一次**主板KEY**停止PWM。示波器Stop仅冻结仪器采集，不是Keil暂停CPU。若看不到波形或发生异常，先KEY停止并保存现状，不反复触发。
6. 保存两通道同屏PNG／屏幕照片和可用的CSV原始波形，保留时间轴、电压轴、倍率、通道名、触发、测量值及采样率。不要只截一个频率数字。记录是否在KEY松开后抓到、是否已KEY停止。
7. 结束保持驱动OFF、动力电池未接；断DAPLink USB后才移探头。第一轮到此，不顺手测AO1／AO2或连接动力试转。

## 5. 预期与判读

| 测点 | 当前代码的预期（未测） | 判读边界 |
| --- | --- | --- |
| PE9／CH1 | 约0–3.3V方波，20kHz，周期约50µs；高约15µs、低约35µs，正占空比约30% | 这是从时钟／寄存器计算的名义值，不填成实测值；检查实际幅值与脉冲形状 |
| 驱动AIN1／CH2 | 应收到与PE9基本一致的脉冲 | 主控引脚有而驱动端无或明显失真时，定点检查测点／夹具／这一段信号路径，不要求重认整套接线 |
| 停止后 | 两点恢复低电平 | 本轮已有板内停止配对，现场只记录外部恢复低，不重复采同一组Watch |

两处都正常时，确认的是**无动力条件下**的控制输出与传输，仍不能证明驱动上电后的输入、VM、H桥输出或电机正常。两处都无波形／幅值异常时，先带回基线、触发状态及真实波形，后续需区分仪器／探头设置、源端配置与外部负载等边界，不能立刻判代码错误或驱动坏。若自动读成70%，先核对测量项是否负占空比以及通道是否反相，再保留原图；不能为“修正读数”改占空比。
