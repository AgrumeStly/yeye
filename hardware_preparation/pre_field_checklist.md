## 今晚按顺序完成

1. **无动力恢复与零基线。** 主控将驱动开关OFF并隔离动力，保留DAPLink逻辑供电，接K230数据口；原T/R/G三线保持，V线不接。Keil5用Project → Open Project打开上表工程，选LowSpeedLap，Project → Rebuild all target files检查0错误0警告；Flash → Download，检查Programming Done／Verify OK；Debug → Start/Stop Debug Session后Run。不按KEY。核对下表零基线。板卡下载及每次动力动作顺序执行。
2. **新电源测量与固定。** 动力仍与负载隔离，主控按[既有电压档／M01说明](i05_measurement_guide.md)测新电池自身放电输出端并记录V；不拿5V稳压轨当电池电压，不用电流档跨接。核对连接器牢固、绝缘与电池固定，沿已确认接法恢复。已充满／额定值与实测值分别填写。没有取得电气依据时先做后续无动力通信，不启动电机。
3. **无动力通信。** 主控先回报零基线及K230连接；再顺序执行现有`uart_probe`助手。预期180个无效PATH＋末尾STOP，`accepted=181`、`received=180`，最后steering=-600，路径许可0，PWM0，UART总错误及五类分项0。首次错误先保存读数，不清零绕过。新连接端口须重新枚举，COM9为已见DAPLink，K230旧COM10不保证沿用。
4. **两次单轮校准。** 无动力检查通过、电气条件明确且两轮完全悬空后，主控开驱动，KEY每次长按约1—2秒再松开，先左轮约500ms，停稳后再右轮约500ms。仅相应轮向车头方向运动，随后撤驱动。核对phase2／error0／state1／UART错误0／run_ms3000。方向、脉冲或输出异常立即断动力，保留本轮失败；复位会丢失映射，须重新校准。
5. **新电池重复直行。** 助手在上述实物与读数确认后才运行`motor_straight`，收到READY后主控单次KEY。每轮40／40RPM、最多3秒，等待两轮停稳；同一输入窗口内可再次人工启动，逐次记录，队内目标连续3次均双轮向前起转、正常LIMIT且UART错误0。每次保存`g_lap_last`后才做下一次，因为新RUN会覆盖快照。不以最后一帧速度代替持续同速证据。
6. **差速复核。** 顺序运行`motor_right`（+500，左60／右20RPM）与`motor_left`（-500，左20／右60RPM），各人工触发一次、3秒。切换脚本会发送STOP，必须先停稳，不在单轮校准或RUN中切换。记录转向关系、实际起转、停止及最后快照。
7. **停车保护。** 分开组织两轮：持续直行输入下主控KEY触发停车；另一轮进入RUN且两轮稳定转动约1秒后，仅拔K230 USB使视觉断源，保留DAPLink主板和驱动供电。须先确认K230确由该USB供电，否则此动作不能模拟断源。记录实际撤驱动和滑行停稳、真实reason／UART分项。`LINK=2`、`TRANSPORT=10`需分别解释；LIMIT11或NO_FEEDBACK7提前停止不算断源通过。恢复脚本后不得自动再起转。故障后先断动力、取证，再复位与重新校准。

停机是PWM归零／H桥00滑行，不能据此声称立即机械停稳。运行中保持Keil Run，不单步、不暂停、不设断点。起转、轮侧或故障不符合即结束该轮，不通过放宽超时／提高PWM覆盖问题。
