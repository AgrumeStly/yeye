## 主控纯Keil操作

1. 下载时**驱动OFF、XT30动力电池拔开**，UC2不接。沿用DAPLink五线供主板，天空星Type-C空着，两板共地且不并联5V／3V3。主控重新打开`D:/Projects/yeye/control/MDK-ARM/yeye_control.uvprojx`，目标下拉选择 **MotorContinuous**，不能选仍会500ms停止的MotorBench。
2. 若在调试中先Ctrl+F5退出，再Project → **Rebuild all target files**。本机构建应0错误0警告，Code5164、RO424、RW64、ZI1288。新目标本地调试项已从已用的MotorBench复制，原目标设置保留；Options for Target → Debug应为CMSIS-DAP、SW、1MHz，Flash Download为STM32F4xx 512KB／0x08000000，Utilities使用Debug Driver。不要换为Simulator。
3. 点击 **Flash → Download**，等Programming Done、Verify OK。Keil直接使用`build/motor_continuous/motor_continuous.axf`，无需终端或手选BIN。退出调试；动力仍断开，拔插DAPLink USB使主板重启，KEY／BOOT0松开，确认每组1次待机灯。需要核版本时仅在电池拔开时用Watch查看0x020B1001、ms递增、fault0，然后退出调试再复位回待机。
4. 电机固定、轮子悬空、线束远离轴，确认Keil已退出调试。驱动OFF时连接XT30，再将驱动ON。先不按键，应无自行转动。待机每组1闪时，**KEY长按到常亮，再松开**：只A桥持续输出，不再自动切到双闪。B桥不运行，A不是已标定的左轮或前进方向。
5. **再按一次KEY即可停止并锁定**；真正切断动力使用驱动OFF／拔XT30，不只拔主板电源。00滑行不保证机械立即静止。若A仍完全不转／仅抖动，在约1–2s内停止并断动力，不保持堵转等待，也不自行提高占空比；持续输出本身不保证起转。

本目标没有编码器、堵转、电流或温度检测；持续模式不等于电机可无人看管运行。测试中不接动力单步／打断点。主控回报选中的目标、Verify结果、KEY松开后A是否转动／声音、KEY停止是否有效；没有反馈不标记通过。
