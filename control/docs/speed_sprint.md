# SpeedSprint：比赛直线带载最高同速试验

日期：2026-11-01（北京时间）。维护：主控／01；主控／02地面验证，00汇总。[任务C-02G](../../project_planning/tasks/C-02G.md)。依据：主控明确要求寻找比赛直线段的最快同速；此前60RPM悬空重复初验见[C-02F](../../project_planning/tasks/C-02F.md)。

软件及模型已通过，**本版未下载、未取得地面最高速度**。主控已确认脱开DAPLink后有独立5V供电，但切换时需先让主板断电。当前版支持重新上电后用车载KEY校准、确认和选档，Watch为可选观察入口。本程序用于赛前在本车负载、比赛相似地面及供电条件下，逐档寻找最高已确认候选。编码器同速不能证明车体不跑偏，更不能证明能安全进入锐角弯。

## 工程与行为

打开[MDK-ARM/speed_sprint.uvprojx](../MDK-ARM/speed_sprint.uvprojx)，唯一目标 **SpeedSprint**，版本`0x020F1002`。复用真实`speed_match_main.c`、编码器和PI，仅新工程定义`SPEED_SPRINT_TARGET=1`，链接新增`speed_sprint.c`。原SpeedMatch仍为60RPM／50%默认限制，重新构建BIN与原已验固件逐字节一致。

| 项目 | 当前实现与含义 |
| --- | --- |
| 校准 | 复位后先两次长按松KEY，逐轮50%／500ms，建立通道与前进符号；仍须悬空亲眼确认轮侧和朝车头方向 |
| 起步 | 共同最终目标初值60RPM，内部设定从10RPM按300RPM/s上升；左右独立PI，不要求PWM相同 |
| 高速能力 | 仅本目标允许0..100%PWM、目标10..450RPM；450是沿用采购标称资料的搜索软件上限，100%是允许输出上限，都不是本车实测最快值 |
| 时空退出 | 每次启动锁定500..3000ms；默认3秒。任一轮估算前进轮程到达默认1500mm时先撤驱动；二者先到者结束，不会自动重跑 |
| 轮程 | 使用分别CPR及默认67.5mm轮径参考，原轮组历史CPR沿用；轮程不等于精确车体位移。轮径须按受载实物核对 |
| 编码器达标 | 内部斜坡已到最终目标，左右各距目标≤5RPM、互差≤5RPM，且结束前连续≥500ms；均为队内指标 |
| 逐档提高 | 每次编码器达标后由主控确认地面无明显跑偏、无触边、正常停稳，再在待机短按KEY接受。同档同设置连续接受3次，记录best并建议+20RPM；450后保持450；跳过上一轮确认就重跑会打断连续计数 |
| 失败区别 | 共同欠速且100%饱和持续≥500ms标为饱和；距离／时间到但未达标记为未验证。一次失败可能来自空间、增益、电量或负载，不能称为物理极速 |
| 明显不同步 | 起步500ms后，两轮差>20RPM连续200ms即故障撤驱动；斜坡中也监督，不把长时间单侧跟不上拖到3秒 |
| 原保护 | KEY原始电平立即撤驱动；无反馈300ms、反向、超速600RPM、样本过期、非法配置、硬件／看门狗和异常保护保留。KEY停止及其它故障均锁定 |

撤驱动采用两桥输入00滑行，**不含主动刹车、机械停稳或弯道减速保证**。默认1500mm只限制驱动轮程，不能据此假定1.5m空地足够；20ms采样也有一个窗口的检测延迟。主控／02须量可用直线、留出已验证的滑行停车距离，并在不足时缩短配置或停止该档试验。没有视觉循迹／地面偏移检测，不直接接到HardwareBench或修改视觉协议。

## 主控在Keil5的操作

1. 驱动OFF、断XT30动力，先固定车架并悬空双轮。供电沿用已确认方式，见[原SpeedMatch操作](speed_match.md)与[硬件入口](../../hardware_preparation/README.md)，不叠加主板电源。
2. Ctrl+F5退出旧调试。Project → Open Project打开本独立工程，确认目标SpeedSprint；Project → Rebuild all target files应0错误0警告。Options for Target → Debug核对CMSIS-DAP／SWD／1MHz，沿用已确认下载器和STM32F4xx 512KB／0x08000000 Flash算法。
3. Flash → Download，等待Programming Done／Verify OK。有线核对时可Ctrl+F5进入调试、F5运行，确认`g_speed_revision=0x020F1002`、`g_speed_fault=0`、`g_speed_match.error=0`；Watch及周期刷新仅供观察，电机转动期间不暂停、单步或打断点。
4. **按主控当前接法切换供电时：保持驱动OFF、先将主板断电，再移除DAPLink，再接入已确认的独立5V并上电。** 不并接DAPLink电源和车载5V，不在断电前的Watch里设置临时参数指望重启后仍有效。独立5V的实际接入端未在本轮详述，本程序不新增供电接线方案。源码默认目标60、距离1500mm均在重启后生效。
5. 主板重新上电后，先固定车架、双轮悬空，保持KEY松开；按原流程两次长按约1–2秒再松KEY（实物丝印，对应WKUP），分别完成左、右500ms校准。每次只允许预期轮朝车头转，方向错误立即断动力。不需要进入调试模式，校准每次断电／复位后都要重做。
6. 两次校准完成并停稳后，保持独立5V运行、不RST，将车辆放到准备好的地面直线起点，以60RPM开始。可用直线须大于驱动轮程并另留实测停车余量；若默认1500mm不适合场地，先在源码`g_sprint_config`修改初值、重新编译下载，断电后的Watch修改不会保留。
7. 长按KEY约1–2秒，待绿灯常亮后松开，执行本次双轮试验。结束并停稳、绿灯开始下节报数后，先看状态：2短闪表示编码器达标，4短闪表示未达标。主控观察全过程是否跑偏／触边／异常，填写[现场记录](../../testing/2026-11-01_speed_sprint/acceptance_record.md)。
8. 若为2短闪且地面表现合格，**短按KEY约0.2–0.5秒再松开**接受一次。确认不会驱动电机；重新摆正到同一起点，再长按1–2秒松开复测。每次地面合格只接受一次，不将悬空测试接受为地面结果。第三次接受后目标报数变为080，再按同样方法测试80、100、120……；建议变化不会自行启动。
9. 出现跑偏或不想继续提高时，停稳待机**长按KEY约3秒，待绿灯由常亮转快闪再松开**，程序取消这次启动、拒绝未接受的最后结果，并退回最高已确认档、关闭升档。若没有任何3次确认的档位，会提示5短闪及000，并回60重新验证，不宣称60已地面通过。运行中按KEY仍立即停止并锁故障，不接受确认手势；5秒卡键保护保留。
10. 最高档选好后，待机灯会以3短闪开头，后面的三位数就是已选用的最高已确认RPM，**断电前抄下**。故障快闪时先断动力、留证再复位。记录、best和通道映射仍在RAM，断电／RST清空；程序未实现Flash保存，不承诺重新接回调试时RAM不被复位。需要永久采用某个实测目标时再回填源码初值并构建，不用Watch临时值代替持久化。

## 脱线时怎样看绿灯

校准阶段仍按原1／2次短闪提示轮侧。完成双轮校准、停稳待机后，每一帧先报状态，再报三位十进制RPM，然后循环：

| 开头短闪次数 | 含义 |
| --- | --- |
| 1 | 等待下一次试验；后面报下一次目标RPM |
| 2 | 最后一轮编码器达标，等待主控确认地面表现；合格才短按KEY接受 |
| 3 | 已结束升档，保持最高已确认档；后面报已选用的RPM |
| 4 | 最后一轮未达标，不要当作通过来接受 |
| 5 | 确认／选档未受理；000表示还没有可选择的最高已确认档 |

状态短闪后熄灭约1秒，再依次显示百位、十位、个位，位间熄灭至少0.8秒：**0为长亮0.6秒，1..9为对应次数的0.1秒短闪**。例如060是“长亮（0）→6次短闪→长亮（0）”；080则中间8次；120为1次、2次、长亮。这里只显示目标／选用档位，**不是左、右实时RPM数值**；实际同速门槛由程序检查并用状态2报告。

读到状态即可决定下一步，不必每轮等完整报数。结束升档后抄下三位RPM，可以在断电后保留人工记录。若绿色指示始终每0.1秒快闪，则是锁定故障，不按待机报数解释。

## Watch：改哪里，看哪里

有线观察时最少添加：`g_speed_revision`、`g_speed_fault`、`g_speed_config`、`g_speed_match`、`g_sprint_config`、`g_sprint`、`g_sprint_review`。脱线时KEY和绿灯承担操作，无需Watch。本机uvoptx已沿用原下载器并预填，受Git忽略，换电脑须重新核对。

| 字段 | 主控的用途 |
| --- | --- |
| g_speed_config.target_rpm | 下一次目标，默认60，允许10..450；只在停稳待机改。运行中改0仍会紧急撤驱动并锁定 |
| g_speed_match.active.target_rpm／command_rpm | 本次锁定最终目标／当前斜坡设定，区分真正达到候选速度与还在起步 |
| g_speed_match.last_left_rpm／last_right_rpm／last_difference_rpm | 停车前最后一帧滤波RPM，不会被待机零速覆盖 |
| g_speed_match.last_matched_ms | 结束前持续满足最终目标的时间，至少500ms才允许接受 |
| g_speed_match.last_left_pwm／last_right_pwm | 停机前PWM千分比；1000为100%。停车当前输出应为0 |
| g_sprint.last_result | 0无结果；1编码器达标；2饱和欠速；3尚未验证；4故障 |
| g_sprint.stop_reason／last_distance_mm | 1时间到、2轮程到、3故障；保存的驱动轮程mm，不含后续滑行 |
| g_sprint.last_saturated_ms／mismatch_ms | 最长连续满输出欠速时间／明显不同步连续时间，单位ms |
| g_sprint.accepted_runs／best_rpm／next_rpm | 当前档人工接受次数／最高3次确认的候选／下一次目标镜像；新档第一次启动后次数重新从0计算 |
| g_sprint_config.distance_limit_mm | 默认1500，允许200..3000；仅根据实测直线和停车空间设置，不为得到更好看的RPM盲目延长 |
| g_sprint_config.wheel_diameter_mm | 默认67.5，仅几何参考；实际负载轮径／滚动周长有误差 |
| g_sprint_config.search_enabled | 1逐档建议；0只重复当前目标 |
| g_sprint_review | 1接受本次；2拒绝本次；3选择best并关闭继续升档。命令只在停稳待机写，消费后归0 |
| g_sprint.review_error | 0无；1运行／未停稳时命令被丢弃；2无可接受的新结果或故障锁定；3编码器未达标；4无有效best |
| g_speed_match.error／g_speed_fault | 原故障解释见[SpeedMatch](speed_match.md)；新增error=12表示两轮明显不同步。任何故障均先断动力留证再复位 |

需要保持最高已确认档时，脱线用3秒松KEY手势，有线也可待机写`g_sprint_review=3`；有有效best才会选择，之后每次长按1–2秒松KEY仍只运行本次时空窗口。best属于已测档位的最高通过值，默认20RPM分档并不是连续速度的精确极值；在已通过与未通过档之间，可用源码初值或有线待机参数细化目标并关闭自动升档，重新独立验证3次。

参数和best只在RAM有效。更改PI、时间、距离或轮径后不沿用原连续通过次数，旧best在下次启动／选用时失效；现场电量、摩擦、轮胎／结构或载荷改变也须重新验证，软件无法自动判断这些变化。最终比赛直线速度必须低于导致跑偏／失稳的档位，且留出实测弯前减速及停车余量；本版没有将候选值自动写入正式循迹程序。
