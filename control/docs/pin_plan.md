# 主控与硬件：引脚候选表

软件设计候选，2026-10-12；实物未到货，尚未签核。PA2/PA3可选UART适配已写入代码，默认关闭。其余引脚均未初始化。

| 功能 | STM32候选引脚 | 外设 | 到货后需核对 |
| --- | --- | --- | --- |
| 视觉通信TX/RX | PA2 / PA3 | USART2 AF7 | 排针是否引出、接口占用、视觉实际TX/RX、电平与共地 |
| 左编码器A/B | PA0 / PA1 | TIM2 CH1/CH2 | 供电、输出电平、每转计数和极性 |
| 右编码器A/B | PB6 / PB7 | TIM4 CH1/CH2 | 排针与其他接口冲突 |
| 电机驱动控制 | 待定 | 确认AT8236接口后选PWM | 真实引脚、双输入/PWM模式、制动逻辑和上电状态 |
| 调试SWD | PA13 / PA14 | SWDIO / SWCLK | 调试器说明、GND、目标参考电压；保持调试引脚可用 |

以上为MCU端口名，不是排针物理序号，不按表直接接线。硬件交付实物型号、原理图和照片，主控确认资源不冲突后冻结。

正式装配图保存在 `../../hardware_preparation/`。本表仅作软件资源草案。板级当前使用HSI，未设168MHz；改外部晶振/PLL后须同时重算UART BRR、滴答和定时器时钟。

核对来源：[立创天空星原理图](https://wiki.lckfb.com/zh-hans/tkx/hardware/schematic.html)、ST官方设备头文件stm32f407xx.h。最终复用功能与对应芯片数据手册复核。
